## Highlights

- **See the latest files after a deploy.** A normal reload now picks up replaced images, stylesheets, and scripts instead of mixing new HTML with old assets. This also applies to Spot Show's live refresh. Unchanged files can still receive a lightweight revalidation response. [#39](https://github.com/melonamin/spot/pull/39)
- **Let visitors choose when to sign in.** A login app that supports silent sign-in can send signed-out visitors back to a clear notice on the spot's own host, with a **Sign in** link. Visitors who already have a login session can continue through automatically. [#37](https://github.com/melonamin/spot/pull/37)
- **Every spot gets an icon.** Spots without their own browser or home-screen icon receive a default pin, including Spot Show pages. A site's own icon takes precedence, and operators can supply their own branding. [#43](https://github.com/melonamin/spot/pull/43)
- **Screenshot deploys recover cleanly on macOS.** A failed capture or upload no longer leaves a temporary file that breaks later attempts. Watch mode reports screenshot failures, cleans up, and keeps `--open` pending until a complete deploy succeeds. [#41](https://github.com/melonamin/spot/pull/41)
- **Remove unused site types.** Administrators can delete a type along with its stored versions and package files. Spot refuses deletion while any site still uses the type. [#36](https://github.com/melonamin/spot/pull/36)
- **Make comparisons easier to scan.** Spot Show's starter and agent guidance add amber and green backgrounds to distinguish current and proposed states in tables and diagrams. [#42](https://github.com/melonamin/spot/pull/42)

## For integrators

- Automatic delegated sign-in requests carry `prompt=none`. If there is no existing session, the login app can return to `/api/auth/callback?error=login_required&return_to=<path>` instead of displaying its sign-in form. Spot then shows the notice on the site host. The **Sign in** link starts a new request without `prompt`, allowing an interactive sign-in. These use OpenID Connect parameter names; Spot's delegated login flow is not OIDC.
- Other callback errors show a sign-in failure page. Spot controls the `prompt` parameter, including removing one configured in `SPOT_LOGIN_URL`. Login apps that ignore `prompt` keep their existing behavior.
- Static site files now send `Cache-Control: no-cache` and ETags so browsers revalidate stable asset URLs. Restricted content and typed-site data retain `no-store`.

## Upgrade notes

- **Apex navigation changes:** `SPOT_APEX_REDIRECT_URL` now shows a landing page that names and links to the embedding application, rather than automatically redirecting there. This applies to Spot's apex platform pages. APIs, assets, and individual hosted sites retain their existing routes.
- `SPOT_DEFAULT_ICONS_DIR` optionally replaces the built-in icon set. Supply `favicon.ico` and `apple-touch-icon.png` in that directory. Files are read on each request; a missing operator file returns 404 instead of showing the built-in brand.
- There is no database migration or site-file migration required for this release.
- Run `spot update` to get the macOS screenshot fix and the updated Spot Show starter and guidance.
