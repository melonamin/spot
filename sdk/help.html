01

Start here

Publish a folder.

Every Spot needs an index.html. Drop the folder in the browser for the fastest first run, or install the CLI if you’ll deploy more than once.

Bring the folder

A single HTML file works. CSS, images, scripts, and nested folders come along for the ride.

Name the spot

Use a short, durable name. Redeploying the same name updates the site at the same address.

Choose access

Leave it open to your mesh, or invite specific email addresses before you launch.

$ spot deploy project-notes ./dist
⌁

Running with an agent?

Give it this one instruction. The setup guide covers installing the CLI, running spot init, and using Spot’s SDK guidance before deploying.

02

Pick the audience

One spot, two doors.

The mesh address is the default, private workplace link. When a site needs to travel farther, publish a separate internet address—without changing the mesh version.

⌂

On the mesh

Fast, internal, and available only to people who can reach your organization’s private network.

Everyone on the mesh
Invited emails only
↗

On the internet

An optional public address for clients, friends, or anyone outside the mesh.

Anyone with the link
Email PIN protection
!
Internet access is separate.

Inviting someone to the mesh address does not grant access to the internet version. Set each audience explicitly on My spots.

What just landed.

The short version of what changed, why it matters, and where to try it. No archaeology through commit logs required.

v0.5.0August 28, 2026

Automation arrived. Reports grew up.

Spot is easier to put in a delivery pipeline and much better at presenting the result—with scoped repository credentials, richer visual reports, and dependable previews.

  • Deploy safely from CI with named publishing keys limited to one repository-friendly site prefix.
  • Build reports that explain themselves with upgraded Mermaid, code, terminal, diff, image, HTML, and agent-trace blocks.
  • Trust the gallery preview now that screenshot capture waits for deferred rendering, rejects incomplete images, and cannot hang forever.
  • See who delivered the update through clearer peer names and publishing-key attribution in My spots.
